## 3. 결함과 미검증 범위

- 시험 중 발견된 제품 결함: 없음. 시험 작성 중 시각 경계 계산 오류 1건은 시험 쪽 오류였고 설계(경과 200 ms는 VALID, 201 ms부터 STALE)에 맞게 시험을 고쳤다.
- 미검증 범위: 호출자(실제 차량 신호 어댑터, 스케줄러)와 구동기 연동은 범위 밖(아키텍처 6절). 이후 이터레이션의 요구(결정론 재생 OEM-NFR-001, 릴리스 증거)는 이터레이션 4에서 검증한다.
- 실행 시간 시험(IT-013)은 컨테이너(x86-64)에서의 측정이며 대상 ECU의 실행 시간은 검증하지 않는다.
