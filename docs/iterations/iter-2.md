# 이터레이션 2 — 문 단위 규칙(접근위험·ISOFIX·자동 잠금·운전자 명령), 전역 해제(ignition off·화재·과온·성인)

- 브랜치: `feature/iter-2-door-rules`
- 입력 문서: OEM-SWR-001 Rev 1.0 (BL-OEM-1.0), 승인된 개발 계획(이터레이션 1 PR 병합 후, 사용자 "이터레이션 2 시작해줘" 2026-11-27)
- 대상 OEM 요구사항: OEM-SR-002, OEM-FR-002, OEM-FR-003, OEM-FR-005, OEM-FR-006, OEM-FR-007, OEM-FR-001(운전자 명령의 적용 부분)
- 대상 SWR: SWR-001, 002, 003, 005, 006, 009, 017, 018, 020, 048 (신규), SWR-023, 025, 035, 036 (개정). 안전 요구사항 SAF-002(신규)
- 이번에 하지 않는 것: OEM-FR-001의 일반 해제 허용 조건(SWR-004), OEM-FR-004(상태 조회·표시), OEM-NFR-001, OEM-NFR-002 (이터레이션 3~4)

## 계획 조정

- OEM-FR-001(운전자 명령 적용)을 이터레이션 3에서 2로 앞당겼다. 접근위험 억제와 override(OEM-SR-002, FR-003)가 "해제 요청"을 전제로 하기 때문이다. 명령의 일반 해제 허용 조건(Q-04)은 우선순위(자동 잠금 > 운전자 명령)로 가정해 처리하고 SWR-004는 이터레이션 3에 남긴다.

## 결정(가정, OEM 질의 Q-21~23)

| ID | 결정 |
|---|---|
| A-16 | 순위: 전역 규칙(충돌 > sensor_fault > INVALID > STALE > ignition off > 화재 > 과온 > 성인) 다음에 문 규칙(접근위험 > ISOFIX > 자동 잠금 > 운전자 명령). 명령은 일회성 사건 |
| A-17, A-18 | ignition off 위치, 화재·과온·성인 동시 순서 |
| A-19, A-20, A-21 | override는 문 해제를 적용하고 접근위험이 FALSE가 될 때까지 유지. 10초는 10,000 ms 이하 포함. 접근위험이 VALID FALSE가 되면 기록 삭제 |
