## 5. 결함과 미검증 범위

- 시험 중 발견된 제품 결함: 없음. 구현 중 MC/DC로 독립 효과를 보일 수 없는 중복 조건 2곳(접근위험 해제 판정, 차속 입력 상태)을 발견해 제품 코드와 상세 설계(v0.4)에서 제거했다.
- 미검증 범위: 비공개 함수의 직접 호출은 하지 않는다(공개 함수를 통한 간접 시험). 고정 시계 재생(OEM-NFR-001)은 이터레이션 4에서 검증한다. 이터레이션 2 범위 밖의 OEM 요구(OEM-FR-004, NFR-001, NFR-002, 일반 해제 허용 조건)는 이터레이션 3~4에서 검증한다.
