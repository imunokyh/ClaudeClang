| 스냅샷 시각 역행 경계, STALE 경계(200 ms), 열거·시각 하한 경계, 차속 상한 경계 | 잡힘 |

## 5. 결함과 미검증 범위

- 시험 중 발견된 제품 결함: 없음(설계 단계의 점검에서 MC/DC로 독립 효과를 보일 수 없는 중복 조건을 미리 제거했다).
- 미검증 범위: 비공개 함수의 직접 호출은 하지 않는다(공개 함수를 통한 간접 시험). 실행 시간(SWR-031)과 고정 시계 재생(OEM-NFR-001)은 이터레이션 4에서 검증한다.
